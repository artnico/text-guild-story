# Text Guild Story 2.0 (Rebuild) - 仕様書
初めてのソロ向けポチゲー

## 1. コアゲームサイクル

1. 【準備】拠点（町）で素材を消費して装備をクラフト・更新し、ダンジョンを選択。
2. 【探索・戦闘】ダンジョンを進行。手動ポチポチ・オート・完全放置の3種に対応。
3. 【トレハン】モンスターからランダムな称号（プレフィックス）付きの装備や素材を獲得。
4. 【成長】行動（攻撃、被弾、クラフト等）に応じて各種スキルの「熟練度」が上昇。

## 2. 主要システム詳細

### ① バトル＆探索システム（スタミナ制限なし）

- **手動モード:** 「探索する」ボタンを押すたびにステップが進み、戦闘やイベントが発生。
- **オートモード:** 画面を開いた状態で、自動で次々と戦闘や探索ログが進行する。
- **放置モード:** 画面を閉じている間も、経過時間に基づいて裏側で素材やExpが蓄積される。
- **戦闘:** 攻撃力・防御力・素早さをベースにしたターン制（`calcStatus`によるリアルタイム補正）。

### ② 全30種スキル熟練度＆マイルストーン奥義＆総合共鳴システム（超インフレ・盆栽型成長）

単一キャラクターを永続育成する盆栽RPGとして、あらゆる日常行動が永続ボーナス・奥義習得・総合ステータス共鳴に直結する3連動システム。

- **行動連動型の成長:**
  - 攻撃時 ➡️ 装備中の武器種熟練度（素手、剣術、刀術、槍術、斧術、弓術、銃術、魔法）が上昇
  - 魔法使用時 ➡️ 4大属性魔法熟練度（火魔法、水魔法、風魔法、地魔法）が上昇
  - 防御・被弾時 ➡️ 盾術、回避、生存、属性耐性（火耐性、水耐性、風耐性、地耐性）が上昇
  - クラフト時 ➡️ 鍛冶、工作、裁縫、調理、鍛錬が上昇
  - 納品・交換・依頼達成時 ➡️ 交易熟練度が上昇
  - ダンジョン探索時 ➡️ 警戒、強行、探索、採取、行軍熟練度が上昇
- **✨ 熟練度マイルストーン＆固有奥義アビリティ（全30種×4段階 = 120種）:**
  - 各熟練度が Lv.10, 25, 50, 100 に到達するごとに、固有パッシブや必殺奥義が自動解放！
  - 例：刀術Lv.100『神速抜刀 一刀両断』、盾術Lv.50『パリィ反撃』、盾術Lv.100『不落の城壁』、回避Lv.100『空蝉の術』、生存Lv.100『不死鳥の魂』、鍛錬Lv.100『神匠の槌印』、交易Lv.100『世界樹の富豪』など。
- **🌌 総合熟練度共鳴（Total Skill Level Resonance）:**
  - 全30スキルの合計レベル（Lv.50〜2000+）に応じて、全基礎ステータス・最大HP・MP・ATK・DEF・命中・回避・会心率・泥率が永続底上げされる超越共鳴システム。

### ③ トレジャーハンティング＆クラフト

- **ランダムドロップ:** 装備には `[伝説の]` `[頑丈な]` `[呪われた]` などのランダムなプレフィックスが付き、同じ装備でも性能が変化。
- **クラフト:** 各町のダンジョンで集めた固有素材を使用し、拠点で装備を製作。生産熟練度に応じて初期性能や良称号の付与率がボーナスされる。

### ④ 装備・着脱システム（スロット詳細）

プレイヤーは以下の合計9つのスロットに装備を装着できる。装備の着脱により、ステータス（`calcStatus`）にリアルタイムで補正が反映される。

- **武器**（剣・槍・斧・弓・銃など：主に物理ATKに影響）
- **サブ武器**（盾など：主に防御力やガード率に影響）
- **頭**（兜・フードなど）
- **体**（鎧・ローブなど）
- **腕**（籠手・手袋など）
- **足**（ブーツ・靴など）
- **装飾1**（リング・アミュレットなど）
- **装飾2**（同上）
- **装飾3**（同上、最大3つまで重複・別種類を装備可能）

### ⑥ 基礎ステータスと戦闘能力値の計算ルール（calcStatus）

プレイヤーは以下の6つの「基礎ステータス」を持ち、それらに「スキル熟練度ボーナス」や「装備の補正」が加算された後、最終的な「戦闘能力値」が以下の計算式でリアルタイムに算出される。

#### ■ 基礎ステータス（ベース）

- **STR（筋力）**：物理的なパワー
- **INT（知力）**：魔力や精神力
- **VIT（体力）**：肉体の頑丈さ
- **DEX（器用）**：手先の器用さ、技量
- **AGI（敏捷）**：足の速さ、身軽さ
- **LUC（幸運）**：運の良さ

#### ■ 戦闘能力値の算出計算式（ベース値 ＋ ステータス補正 ＋ 装備値）

1. **最大HP** = 100 + (VIT \* 10) + [装備のHP]
2. **最大MP** = 20 + (INT \* 5) + [装備のMP]
3. **物理攻撃力（ATK）** = 10 + (STR \* 2) + [装備のATK]
4. **魔法攻撃力（MATK）** = 5 + (INT \* 2) + [装備のMATK]
5. **物理防御力（DEF）** = (VIT \* 1) + [装備のDEF]
6. **魔法防御力（MDEF）** = (INT \* 1) + [装備のMDEF]
7. **命中率（%）** = 90 + (DEX \* 0.5) + [装備の命中] （最大100%）
8. **回避率（%）** = (AGI \* 0.5) + [装備の回避] （最大50%）
9. **ドロップ率補正（%）** = 100 + (LUC \* 1) + [装備の泥率] （アイテムの基本ドロップ率に乗算）

### ⑦ ジョブシステムと最上級職への転職ハードル

プレイヤーの基礎ステータスは「現在のジョブ」によってベース値が大きく変化する。

#### ■ 初期・中級ジョブ（熟練度のみで転職可能）

- **冒険者**（初期ジョブ：全能力が平均的）
- **魔法剣士**（条件：剣術 Lv.20 ＋ 魔術 Lv.20）

#### ■ 最上級ジョブ（各種ボスの激レア素材 ＋ 高レベル熟練度が必要）

最上級ジョブは圧倒的なステータスベース値を持ち、さらに専用のパッシブ補正がかかる。

1. **【竜騎士 (Dragon Knight)】**（物理・生存特化）
   - 転職条件：槍術熟練度 Lv.80 ＋ 火耐性熟練度 Lv.50 ＋ レア素材 **[究極の竜鱗]**
   - ジョブ特性：槍装備時、物理ATKと最大HPのブースト率が1.5倍になる。
2. **【魔導機工師 (Magitech Master)】**（クリティカル・トレハン特化）
   - 転職条件：銃術熟練度 Lv.80 ＋ 工作熟練度 Lv.60 ＋ レア素材 **[古代の魔導コア]**
   - ジョブ特性：アイテムドロップ率＋50％、銃のクリティカル倍率アップ。
3. **【神聖至高職 (Hierophant)】**（魔法・超回復特化）
   - 転職条件：魔術熟練度 Lv.80 ＋ 水耐性（精神） Lv.50 ＋ レア素材 **[聖人の遺骨]**
   - ジョブ特性：最大MP＋100％、全属性耐性の効果が1.3倍になる。

#### ■ ボスモンスターとレアドロップ

各ダンジョンの最深部には「ボス」が存在し、超低確率でレア素材をドロップする。

- 始まりの森ボス：**森の主・キングラっこ**（ドロップ：ラッコの王冠 5%）
- 忘れられた廃鉱ボス：**古代のアイアンゴレム**（ドロップ：[古代の魔導コア] 1%）
- 霧深い沼地ボス：**沼地の変異ヴルム**（ドロップ：[究極の竜鱗] 1%）

### ⑧ 統合成長システム（PLV・ステ振り・JLV・熟練度の整合性）

プレイヤーは「足し算のベース育成（PLV、ステ振り、JLV）」と「掛け算のインフレ育成（熟練度）」の4つの異なる軸でキャラクターを無限に強化できる。

1. **プレイヤーレベル（PLV）：【大いなる器】**
   - 上がりやすさ：遅め（重みがある）。
   - 特典：レベルアップ時に「ステータスポイント」を5獲得。転職しても維持。
2. **ステータスポイント（ステ振り）：【自由なビルド】**
   - 特典：獲得したポイントを STR/INT/VIT/DEX/AGI/LUC に自由に割り振り、基礎ステータスを尖らせることができる。転職しても振り直す必要はなく、そのまま維持される。
3. **ジョブレベル（JLV）：【コレクター要素】**
   - 上がりやすさ：中程度（職ごとに独立して記憶）。
   - 特典：最大レベル（MASTER）に達すると、固有のパッシブスキルを習得。このパッシブは他のジョブに転職しても「アビリティ枠」にセットして共有できる。
4. **各種熟練度：【無限の盆栽ブースター】**
   - 上がりやすさ：無限（行動ごとに蓄積、上限なし）。
   - 特典：1〜3で完成した基礎ステータスに対し、「装備している武器」や「行動」に応じて％単位の強力な乗算（掛け算）ブーストをかける。

### ⑨ 手動探索（3スタンス＋選択肢イベント）＆ オートクリックチャンス

1. **手動3スタンス（探索中・戦闘中共通）**
   - **👣 慎重に進む / 🛡️ 堅実攻撃（警戒熟練度）**：HP・MPを回復しながら安全に進行。警戒熟練度に応じてVIT・DEF・MDEFが上昇。
   - **⚔️ 強行突破 / 💥 強襲攻撃（強行熟練度）**：2〜4歩一気に進行し、レアモンスター遭遇ウェイト3倍＆戦闘時与ダメージ1.3倍以上・獲得熟練度1.5倍。強行熟練度に応じてSTR・ATKが上昇。
   - **🔍 集中探索 / 🎯 急所狙い（探索・採取熟練度）**：手動採取限定素材や選択肢イベントを高確率で発見し、戦闘時は命中・会心・スキル発動率2倍・ドロップ率+50%。探索・採取熟練度に応じてDEX・LUC・ドロップ率が上昇。
2. **TRPG風・分岐選択肢イベント（手動限定）**
   - 鍵付き宝箱・古代の魔力祭壇・希少鉱脈・強敵の縄張りの4種が発生し、ステータスと熟練度の合計値で成功率が変動。
3. **オート探索中の「行軍（放置）熟練度」＆ クリックチャンス**
   - オート探索中は毎歩「行軍熟練度」が上昇（HP/MP自然回復・AGIボーナス）。さらに一定確率で5歩限定の「⚡クリックチャンス（遺構発見・レア敵誘い出し・大鉱脈採掘）」が出現。

### ⑩ 素材・武具交換屋（ギルド交易カウンター）＆ 特殊効果アクセサリー

- **不要な素材・未装備クラフト武具の多機能一括納品**：
  - 素材だけでなく、熟練度上げや良称号狙いで量産した大量のクラフト武具を瞬時に交換ポイント（Pt）へ変換可能。
  - 修飾子ティア（Tier 0〜Tier 5）に応じて納品レートが **×0.5〜×15.0** に変動。ギルドランク特典やジョブ超越特化の納品Pt乗算ボーナスも全額適用。
  - **充実した一括納品カテゴリ**：
    - `🛡️ Tier1以下(普通)の武具を一括納品`
    - `✨ Tier2以下(良質まで)の武具を一括納品`
    - `⚒️ +0未強化の通常装備を一括納品`（レア・激レア・強化品は自動保護）
    - `🚨 未装備品を全納品 (強化品除く)`（確認ダイアログ付きでまとめて安全に換金）
    - `🧹 Tier0(粗悪)素材を一括納品` ｜ `📦 Tier1以下で10個超の余剰素材` ｜ `📦 20個超の余剰素材 (レア除く)`
  - **誤売却防止の安全保護設計**：現在装備中の武具、鍛錬+1以上の強化装備、激レアドロップ品は一括納品から自動的に除外保護。
- **前エリアのボス討伐による段階解放**：
  - エリア2以降の交換品は「前エリアのボス討伐（図鑑登録）」によって順次解禁され、段階的な攻略サイクルを保護。
- **エリア別・特殊効果つき限定アクセサリー（全6種）**：
  1. `森精ラッコの豊穣お守り`（エリア1）：毎歩HP・MP2%回復 ＆ 採取獲得数+1個
